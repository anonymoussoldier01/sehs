# Design plan — SEHS Study home (master brief §5)

**Subject:** Free, no-account study site for Victorian Selective Entry (ACER,
June exam, Year 9 entry). ~1,542 resources, 4 mocks, 14 decks, 80 prompts.

**Audience:** Year 8 students (12–14) + parents deciding. Both must feel
"we can do this" in 5 seconds, no anxiety, no comparison.

**Primary job of this page:** Pick a target door → start a first mock in
under a minute. Everything else (topics, stats, FAQ) is reassurance below.

**Concept:** "Four doors, one desk." Left-anchored editorial hero (7 cols
text, 5 cols live card) on deep navy with masked spotlight + grain; cream
exam-paper sample card as deliberate contrast; four tall SVG door arches
that swing open on selection (the ONE signature interaction); ledger-quiet
cards below.

**Token system:** Base #0A0F1E / S1 #101734 / S2 #162046, border 8% white,
text #EDEFF7/#A9B0C8, cream #F4EBD9, ONE amber #F5B83D (CTA, underline, key
numbers), crest colours tiny accents only. Fraunces display + sans UI + mono
numerals. Radius 10/16/999. 12-col, ONE container, 1px dividers.

**Anti-template choices:** masked spotlight (no rect edge) + grain; SVG
highlighter BEHIND text below baseline; crest strip = 4-col clickable
crest+name only; sample card = ruled cream paper with red-pen tick; doors =
arches with height rhythm + floor light spill, not rounded cards; amber
primary with dark ink (not default blue); max one focal point/viewport.

**Slop self-check:** default blue primary — fixed (amber). Inter-on-navy —
fixed (Fraunces + system sans). Identical rounded cards — fixed (arches,
ledger, paper contrast). Gradient blobs — purged (masked spotlight only).
Everything centred — fixed (left-anchored). Hover-lift everywhere — purged
(150ms border/glow only). Fade-up everywhere — purged (one load, one select).
